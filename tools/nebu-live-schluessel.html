NEBU – Schlüssel für die Live-Umgebung

Diese Seite läuft nur in deinem Browser und sendet nichts ins Internet. Die Werte erscheinen nur hier. Trage sie in Netlify ein: Projekt shop.nebusushi.com → Project configuration → Environment variables (bei Schlüsseln „Contains secret values“ anhaken). Danach diese Seite schließen. Für Test und Live immer unterschiedliche Werte verwenden.

Den Schlüssel für den Druckdienst (NEBU_PRINT_AGENT_TOKEN) erzeugt das Live-Installationsskript direkt auf dem Restaurant-PC.
